# 📖 Phone Book Application

## 📌 Overview
The **Phone Book App** is a mini-project implemented in C that allows users to manage contacts efficiently.  
It supports storing multiple phone numbers, email addresses, and addresses under a single contact. The app also provides options to create, view, edit, delete, search, and save contacts persistently.

---

## 🎯 Features
- **Create Contact**: Add a new contact with name, phone numbers, email, and address.  
- **Multiple Numbers**: Option to store multiple phone numbers for one contact.  
- **Edit Contact**: Modify existing details or add new ones.  
- **Delete Contact**: Remove a contact by name.  
- **Find Contact**: Search for a contact by name.  
- **View All Contacts**: Display all stored contacts.  
- **Save to File**: Persist all contact details in a file.  
- **Reload Data**: On relaunch, previously saved contacts are loaded.
